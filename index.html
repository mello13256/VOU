~/como-trabalho

        
Como trabalho

        
Cinco passos, sem surpresas. Só decide no fim, depois de ver o projeto a funcionar.

      


      
    
        
  1. 
          01
          
    
            
    Conta-me a ideia
    
            
    Explica o que precisa — em duas linhas ou com todos os detalhes. Eu digo se dá para fazer, como e em quanto tempo.
    
          
    
        
    2. 
        
  2. 
          02
          
    
            
    Eu desenvolvo
    
            
    Ponho mãos ao código e construo o projeto do início ao fim, com pontos de situação pelo caminho.
    
          
    
        
    3. 
        
  3. 
          03
          
    
            
    Recebe o projeto a funcionar
    
            
    Entrego a coisa pronta e publicada, para abrir, usar e mostrar a quem quiser.
    
          
    
        
    4. 
        
  4. 
          04
          
    
            
    Verifica se está como queria
    
            
    Testa com calma. Se algo não estiver como imaginou, digo o que dá para ajustar e ajusto.
    
          
    
        
    5. 
        
  5. 
          05
          
    
            
    Decide se compra
    
            
    Só depois de ver o resultado é que decide. Sem compromisso antes disso.
